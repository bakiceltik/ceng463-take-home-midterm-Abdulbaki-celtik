# Notebooks

Use this directory for exploratory work that later gets cleaned up into the `src/` modules and the report.

Suggested naming:

- `01_q1_regression_eda.ipynb`
- `02_q2_imbalance_checks.ipynb`
- `03_q3_embeddings.ipynb`
- `04_q4_cluster_visuals.ipynb`
- `05_q5_error_analysis.ipynb`

Keep final claims and reproducible runs in scripts or modules, and treat notebooks as supporting analysis rather than the single source of truth.
