\section{Introduction}

This report addresses all five questions from the CENG 463 take-home midterm. The project is implemented with an emphasis on reproducibility, consistent random seeds, explicit preprocessing, and clear separation between exploratory work and report-ready experiments.

\subsection{Reproducibility Checklist}

\begin{itemize}
  \item All experiments use explicit random seeds and stored configuration files.
  \item Model comparison uses fixed data splits unless a controlled comparison requires otherwise.
  \item Figures and tables are generated from code and stored in the repository outputs.
  \item Final test-set reporting is reserved for the last evaluation step.
\end{itemize}
